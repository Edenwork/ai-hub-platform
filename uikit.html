/* GLOBAL CSS VARIABLES 架構：Reference / Palette (底層：物理來源) -> Brand Palette (來源) -> System Tokens (語意化，最常使用) -> Component Tokens (元件專屬) */
:root {   /* ── 1. Component ── 元件專屬（必要時才定義，少用） */
  --comp-card-radius: 30px;   --comp-card-shadow: 0 3px 5px rgba(0,0,0,0.05);   --comp-card-border: 1px solid var(--sys-color-outline-variant);   --comp-btn-primary-bg: var(--sys-color-primary);   --comp-btn-primary-text: var(--sys-color-on-primary);   --comp-btn-hover-bg: var(--sys-color-primary-container);   --comp-btn-hover-text: var(--sys-color-on-primary-container); }

命名規範

主要樣式設定根據以下參數：

  • 按鈕：intent - primary (主色)、secondary (灰色)、white (白底黑字)、whiteDark (黑底白字)、outline (黑框)、outlineHoverPrimary (hover 轉主色)、outlineGray (灰框)、outlineDanger (警示紅框)、link (連結透明底)。
  • size - md (預設)、lg (有最小寬度)、sm 、xs (特殊小尺寸)
  • rounded - full (預設)、md (基本圓角)
  • position - 按鈕內部 justify 位置。
  • - primary：深一點、穩重 → 主按鈕、header
    - accent：亮一點、活潑 → hover、focus、badge、選中態
類別 描述
color, fill 預設基礎顏色值。
surface 僅適用於頁面底層特定元素的背景。
surface-container 僅適用於位於表面之上的元素的背景，並包含其他 UI 元素或元素，例如文字或圖示。
on-surface, on-feedback, on-accent 適用於位於表面或表面容器（例如按鈕）上的內容（文字或圖示）。
border 用於容器周圍的邊框、描邊或分隔線。

Cards

  • 介紹文字最多50字，對於較長的內容，可以添加 .text-truncate 類別，以透過刪節號截斷文字。 需為 display: inline-block 或是 display: block，並設定 CSS Style 高度 max-width: 150px。
  • 自訂的多行截斷，可以添加 .line-clamp-3 類別，例如 3行 就設定 -webkit-line-clamp: 3。
.line-clamp-3 {   display: -webkit-box;   -webkit-box-orient: vertical;   -webkit-line-clamp: 3;   overflow: hidden;   /* max-height: 4.5rem; 假設 line-height 1.5rem × 3 = 4.5rem */   /* line-height: 1.5rem; */
}

Color

  • style.css 設定 :root，相關css以 color: var(--main-color) 來匯入，盡量不要用色碼去設定 color 避免規範混亂。
